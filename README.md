# 📦 CRUDS Product Management System

A simple and interactive product management system built with HTML, CSS, and JavaScript. This project allows users to manage their inventory by creating, viewing, updating, and deleting products.

## 🚀 Features

- **Create Products:** Add new products with their details.
- **Read Products:** Display all products in an organized list.
- **Update Products:** Edit existing product information.
- **Delete Products:** Remove individual products from the inventory.
- **Product Details:** Manage product name, price, category, and quantity.
- **Inventory Management:** Keep product information organized in one place.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
